# Palavra & Wort · 私人词汇闪卡

巴西葡语（A1–C1）、德语（A1–C1）、英语（B1–B2）分级词汇闪卡。纯静态网页，可以直接放在 GitHub Pages 上，装到手机主屏幕当 App 用。

## 功能

- 间隔重复复习，四档评分，掌握程度分五级
- 每日打卡：每天学满 Z 个新词并清空当天复习
- 学习计划：选目标级别、总词数和完成日期，AI 按主题分批生成整套词表和例句，每天自动分配新词数，显示进度是否落后
- 拍照识词：拍课本、笔记、菜单、路牌，AI 挑出值得学的词，勾选后加入词库
- 生词堆、按级别 / 掌握程度复习
- 录入自己的词：「查词典（免费）」自动查词性、释义、阴阳性 / 复数 / 音标、中文翻译和例句（维基词典 + MyMemory，不需要 key），结果做成候选可以点选
- 可选 DeepL：在「设置与备份」里填自己的 DeepL 中转站地址（Cloudflare Worker，见 `worker.js` 和设置说明），查词时翻译优先用 DeepL；没填就用 MyMemory，并提供「在 DeepL 中打开」链接
- 德语词自动查 DWDS：词性、音标、词频、歌德 A1–B1 词表级别和冠词；完整释义和例句提供 DWDS 链接
- 也可以用 AI 补全释义、例句、记忆提示，并画一张记忆插图（需要 Claude API key）
- 每个词可以写自己的例句，让 AI 检查改错
- 用麦克风录下自己的发音（单词、例句各一段），和系统朗读对比
- 离线可用；数据保存在本机浏览器，可导出 / 导入备份文件

## 放到 GitHub Pages

**最少只需要 `index.html` 一个文件**：词库和页面上的 logo 都已经写在里面。其余文件（图标 PNG / SVG、`manifest.webmanifest`、`sw.js`）都和 `index.html` 放在同一层，没有子文件夹，用于装到手机主屏幕时显示图标、离线使用，建议一起上传。

1. 把这个文件夹里的所有文件放进一个仓库（或现有 Pages 仓库的一个子文件夹，例如 `vocab/`）。
2. 仓库 Settings → Pages → 选择分支（通常是 `main`）和根目录，保存。
3. 一两分钟后打开 `https://<用户名>.github.io/<仓库名>/`（子文件夹就在后面加 `vocab/`）。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用（界面、逻辑、样式） |
| `data/*.json` | 内置词库的原始文件（已经写进 `index.html`，上传时可以不传；改词库后需要重新生成 `index.html`） |
| `manifest.webmanifest`、`icon*.png`、`icon.svg`、`apple-touch-icon.png`、`favicon-32.png` | 装到主屏幕用的名称和图标 |
| `sw.js` | 离线缓存 |
| `logo/` | Logo 原文件：单独图标（mark.svg）、横版标志（浅色 / 深色，SVG 和 PNG）、1024 像素大图 |

## 数据和隐私

- 学习进度、自录词、例句、图片、录音都存在你自己设备的浏览器里（localStorage + IndexedDB），不会上传到任何服务器。
- 换设备或清理浏览器前，在「设置与备份」里导出备份文件。
- Claude API key 只存在本机，只发送给 `api.anthropic.com`，不会写进备份文件。
- DeepL key 只存在你自己的 Cloudflare Worker（Secret 变量）里，网页里只保存中转站地址；中转站用 `ALLOW_ORIGIN` 限制只接受你自己网站的请求。
- 查词时要查的单词会发给维基词典、MyMemory、DWDS（德语）和你的 DeepL 中转站（如果填了）。

## 改词库

`data/` 里每一行是一个词：

- 葡语：`[单词, 词性, 中文, English, Français, 例句, 例句中文, 例句英文]`
- 德语：`[单词, 词性, 复数/变形, 中文, English, 例句, 例句中文, 例句英文]`
- 英语：`[单词, 词性, 音标, 中文, 英文释义, Deutsch, 例句, 例句中文]`

改了词库或 `index.html` 之后，把 `sw.js` 第一行的 `palavra-wort-v1` 改成 `v2`、`v3`……，已安装的设备才会拿到新版本。
