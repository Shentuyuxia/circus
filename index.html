怎么录入

输入单词，点「查词典（免费）」或按回车：自动查词性、释义、阴阳性 / 复数 / 音标、中文翻译和例句，先填上第一个结果，其余的做成候选，点一下就换。不需要 API key。

有 API key 的话，也可以点「AI 补全并配图」：AI 会写记忆提示，再画一张插图。所有内容都可以改，满意了再保存。

也可以不用 AI，自己填写、上传图片，再用麦克风录下自己的发音。

生词堆

生词堆怎么用

不熟的词点卡片右上角的星标，就会放进生词堆；在词库里也可以直接加。

「复习生词堆」不管有没有到期，会把堆里的词全部过一遍。评为「简单」的词会自动移出生词堆，其余的留着下次再练。

点单词可以打开详情，给它配图、写例句、录发音。

掌握程度分级

复习间隔怎么算

每次评分决定下次出现的时间：「忘了」当天重来；「模糊」间隔略增；「记得」按 1 → 3 → 约 7 → 约 18 天递增；「简单」跳得更远。

间隔达到 30 天以上的词算「精通」。

备份与恢复

所有内容都保存在这台设备的浏览器里：学习进度、你录入的词、图片、录音和例句。换设备、清理浏览器之前，先导出一份备份文件。

从 Claude 里那个版本搬过来：在那边「进度」页点「导出备份」，再在这里导入同一个文件。

AI 补全、配图、检查例句

这个独立版直接调用 Claude API，需要你自己的 API key（在 console.anthropic.com 创建）。API 按用量单独计费，和 Claude 订阅不是同一个账户。

key 只保存在这台设备的浏览器里，只发给 api.anthropic.com，不会放进备份文件。

DeepL 翻译（可选）

DeepL 不允许网页直接调用它的接口（那样会暴露你的 key），所以需要一个你自己的小「中转站」。用免费的 Cloudflare Worker 就够了，设置步骤见随附的「DeepL 中转站设置说明」。

设置好后，「查词典」里的中文、法语 / 英语 / 德语翻译和例句翻译都会优先用 DeepL；没设置时用免费的 MyMemory。

装到手机主屏幕

iPhone（Safari）：

  1. 用 Safari 打开这个页面
  2. 点底部的「分享」按钮
  3. 选「添加到主屏幕」

安卓（Chrome）：

  1. 点右上角菜单 ⋮
  2. 选「安装应用」或「添加到主屏幕」

装好以后像 App 一样打开，没网也能复习（AI 功能需要联网）。
